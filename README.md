# Mind the Gap · Midterm Workshops (Introduction to Statistics, CUD)

Narrated, interactive web pages for the three midterm-preparation workshops.

- `index.html`: the series page
- `workshop-02.html`: Workshop 2 · Read the formula (mean, variance, SD, CV, E(X))
- `workshop-03.html`: Workshop 3 · Your calculator in the final (step-by-step video)
- `calculator.html`: online scientific calculator (QR code in the workshop slides)
- `assets/`: shared lecture engine (same as the GED 102 site)

Live site: https://nadiamek-tech.github.io/MindTheGap/
